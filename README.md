# UNED Study Content

Repositorio de contenidos académicos para UNED Study.

Las asignaturas se almacenan bajo `subjects/<subject_id>/subject.json`. El contenido se versiona aquí; el progreso de los usuarios nunca se guarda en este repositorio.

El contrato de contenido, ejemplos y reglas para LLM se desarrollan en una rama y se incorporarán mediante pull request.
